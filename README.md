# JavaScript Greeting Builder

A beginner-friendly JavaScript project from the [roadmap.sh JavaScript Greeting Builder challenge](https://roadmap.sh/projects/js-greeting-builder).

This project generates personalized greetings using a person's first name, last name, and time of day.

## Features

- **`formatName(firstName, lastName)`**: Combines a first name and last name.
- **`getGreeting(timeOfDay)`**: Returns an appropriate greeting based on the time of day.
- **`createGreeting(firstName, lastName, timeOfDay)`**: Combines the helper functions to generate a complete greeting.

## Technologies Used

- JavaScript (ES6+)
- Node.js

## Getting Started

### Prerequisites

Install [Node.js](https://nodejs.org/).

### Run the Project

Clone the repository:

```bash
git clone https://github.com/sameer-dev-106/greeting-builder.git
```

Navigate to the project directory:

```bash
cd greeting-builder
```

Run the program:

```bash
node index.js
```

## Example Output

```text
Good morning, Ava Stone
Good evening, Noah Kim
Good afternoon, Mina Patel
```
